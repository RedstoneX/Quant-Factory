# Historical Operator-Workflow References

Despite this directory's retained name, Decision 338 supersedes these files as
approved visual or interaction contracts.

Use the HTML and PNG files only as:

- inventories of useful page content and domain facts;
- records of the seventh iteration's intended responsibilities; and
- evidence of designs that did not support unaided owner comprehension.

Do not use them as targets for shell, composition, density, styling, card
patterns, visual language, interaction behavior, or page topology. Decision 340
supersedes Ideas, Set up, and Run test as independent destinations: their useful
content belongs in Candidates and the selected-Candidate workspace. Dashboard,
Candidates, and Compare require newly owner-approved surface designs. Results
uses the owner-approved Greenfield preview as its exact interaction reference.
Decisions 337–340, `docs/operator-interface-reconstruction.md`, and
`docs/MILESTONES.md` control current work.
