# Historical prototype browser report

This is a path-free sanitized summary of historical browser validation of the
owner-approved standalone preview. It used the omitted private fixture. It is
not proof for the current application, R07, a qualified edge, or profitability.

The historical report covered desktop, tablet, and mobile viewports. It
reported:

- no browser errors or horizontal overflow;
- 52 pixels of bottom clearance and no nested vertical scrolling;
- interval aggregation counts and trade-marker linkage behaving as expected;
- panel resize, layout reset, and Metrics/Trades switching behaving as
  expected; and
- 366 closed trades grouped into linked entry/exit records.

This report does not bind those observations to the current application
revision or target runtime. Current-revision browser proof remains absent.
